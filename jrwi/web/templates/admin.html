What do these do?

Check now runs the same check as the schedule{% if every %} (every {{ every | float | round(1) | string | replace('.0', '') }} hours){% endif %}:

  1. Looks for new posts: reads the members feed from the newest post down. It stops after 15 posts in a row that it already has{% if back_days %}, once it's back more than {{ back_days }} days (the YouTube version of an episode is posted with the older date of its members-only post){% endif %}.
  2. Saves the site's own pages (logo, show pages, perks) when they're more than a day old.
  3. Saves new and changed posts: each post's page, text, comments and files (video, audio, pictures, attachments, linked Google Docs and Drive files), and files an earlier check missed.
    4. {% if comment_days %}
  4. Looks for new comments on posts from the last {{ comment_days }} days.
    5. {% endif %}
  5. Asks TubeArchivist about episodes now on YouTube, when it's connected (see Videos now on YouTube below).
  6. Lines up the video and audio of episodes that are new or changed, so the apps carry your place between them.
  7. Sorts posts into shows, tabs and seasons, and updates the Jellyfin folder.

Full check does all of that, but reads the whole feed, back to the very first post. That updates what the feed shows about older posts (titles, tags, likes, comment counts, whether you can see them), finds anything a normal check skipped, and notes posts the site has taken down. Nothing already saved is downloaded again. It takes longer, mostly for reading the feed, so it's only worth running now and then.

Re-read saved pages: every post page, comment page, feed card and site page is saved as it was downloaded. This reads them all again with the current rules, so a fix in an update also corrects what was archived before it: post text, dates, tags, comments, profile pictures and badges. It runs by itself after an update that changes how pages are read. Nothing big is downloaded again; if the re-read finds files an older version missed, the next check fetches just those.
